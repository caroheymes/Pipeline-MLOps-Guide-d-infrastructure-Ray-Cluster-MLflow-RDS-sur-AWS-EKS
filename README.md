# Pipeline-MLOps-Guide-d-infrastructure-Ray-Cluster-MLflow-RDS-sur-AWS-EKS
Guide de déploiement MLOps d'une infrastructure scalable sur AWS EKS. Orchestration de calcul distribué avec Ray (Kuberay) et suivi des expérimentations/modèles avec MLflow, sauvegardés de manière sécurisée sur RDS (PostgreSQL) et S3 via IRSA (OIDC).
